# 抽獎系統

一頁式抽獎網頁,所有 HTML / CSS / JavaScript 都寫在同一個檔案 [`index.html`](./index.html) 裡,不依賴任何外部檔案或函式庫,直接用瀏覽器開啟即可使用。

## 畫面配置

```
┌─────────────────────────────────────────────┐
│ 🔊音效 ───●───  ☑  [測試]           (左上角,固定懸浮) │
│                                               │
│                 抽獎系統                      │
│ ┌───────────────────┐ ┌─────────────────────┐ │
│ │ 抽獎項目 [刪除][清空]│ │ 中獎名單     ☑刪除中獎項目│ │
│ │                     │ │                     │ │
│ │   (項目清單)         │ │   (中獎清單)         │ │
│ │                     │ │                     │ │
│ │ 新增項目 [___][新增][項目打亂] │ │ 中獎內容 [___][開始抽獎]│ │
│ └───────────────────┘ └─────────────────────┘ │
│                作者: light0986                 │
└─────────────────────────────────────────────┘
```

- 響應式設計:視窗寬度 > 640px 時左右兩欄並排;≤ 640px 時改成上下堆疊(先「抽獎項目」整塊,再「中獎名單」整塊)。整體支援縮到最小 300px 寬不跑版,按鈕/輸入框會自動換行。
- 兩個清單(抽獎項目 / 中獎名單)最低高度都固定 500px。
- 音效控制列在寬螢幕(> 640px)時是**左上角固定懸浮**;縮到 ≤ 640px(上下堆疊版面)時改成**跟著文件排版,顯示在標題正下方**,不再懸浮。
- 上下堆疊版面下,按「開始抽獎」會自動捲動到頁面最上方(方便從頭看跑動特效);中獎項目加入右側名單的當下,會自動捲動到頁面最下方(方便直接看到最新結果)。寬螢幕左右並排時不會有這個自動捲動行為。
- 頁面最下方有一行「作者: light0986」,除了署名,也是上述自動捲到最下方時的錨點(見下方「自動捲動實作方式」)。

## 左側:抽獎項目

- **新增項目**:在下方輸入框輸入名稱後按「新增」或按 Enter,加入清單。
- **項目打亂**(紅色按鈕,位於「新增」右邊):
  - 項目數量 < 2 → alert「請添加至少兩個項目」,不執行。
  - 項目數量 ≥ 2 → 用 Fisher-Yates 演算法隨機打亂清單目前的顯示順序。
- **刪除點選項目**:清單項目可點選反藍(可複選),按「刪除點選項目」跳出確認 `確認刪除{項目名稱}?`(多筆以「、」串接),確認後才刪除。
- **清空全部**:跳出確認 `確認是否清空項目?`,確認後清空整個清單。

## 右側:中獎名單

- **中獎內容**:抽獎前先在右下角輸入框填入本次獎項名稱(預設「中獎」),抽獎時會以粗體 `{內容}:` 的形式加入名單,作為一個「區塊」的抬頭。
- **同一內容連續抽獎會合併成同一區塊**:只要「中獎內容」欄位沒有變更,連續按「開始抽獎」不會重複加抬頭,得獎名字會直接接續加在同一個抬頭底下(區塊內間距較緊,不同區塊之間留較大空隙)。換一個內容再抽獎,才會產生新的抬頭區塊。
- **刪除中獎項目(checkbox,預設打勾)**:
  - 打勾:抽中的項目會從左側「抽獎項目」移除,並加入右側名單(不會再被抽到)。
  - 不打勾:左側項目保留,右側名單新增一筆相同名稱的副本(可重複抽中)。
- **點擊右側任一項目**:項目右側會展開一顆「刪除」按鈕(寬度由左至右展開的動畫),再點擊其他地方(非該刪除按鈕)則按鈕收起(由右至左收合)。
  - 點擊**一般得獎項目**的刪除按鈕:跳出 `是否刪除{項目名稱}?`,確認後刪除該筆;若刪除後該區塊已無任何項目,抬頭也會自動一併移除。
  - 點擊**抬頭項目**的刪除按鈕:跳出 `是否刪除整個區塊?`,確認後連同底下所有得獎項目一次刪除。

## 開始抽獎流程

1. 按下「開始抽獎」時依序檢查:
   - 抽獎項目數量 < 2 → alert「請添加至少兩個項目」,中止。
   - 「中獎內容」欄位為空 → alert「請輸入中獎內容」,中止。
2. 條件都符合後,背景先亂數決定一個目標項目 index,接著跑動特效開始,**畫面所有控件(含音效控制)全部鎖定,無法操作**,直到本次抽獎流程結束。
3. **跑動特效**(總長約 5 秒):
   - 前 2 秒固定每 100 毫秒切換一項高亮(紅色外框)。
   - 後 3 秒切換速度逐漸放緩(等差遞增間隔),最終精準停在目標項目上。
   - 每切換一次高亮項目,發出一聲「嘟」音效。
4. 停在目標項目後,停頓 1 秒,接着:
   - 若「中獎內容」與上次不同(或第一次抽獎),先加入一筆粗體抬頭 `{中獎內容}:` 到右側名單。
   - 依「刪除中獎項目」checkbox 狀態,把抽中的項目加入右側名單(移除或保留左側原項目)。
   - 加入完成後,播放中獎音效(兩聲同音喇叭聲)。
5. 解除所有控件鎖定,可以進行下一次抽獎。

### 自動捲動實作方式(上下堆疊版面專用)

自動捲動**不是**用 `window.scrollTo()` 手動計算位置(早期版本這樣做過,結果會被跑動特效裡逐項高亮的內部捲動互相干擾,導致捲動位置不準、甚至完全沒反應),而是改用瀏覽器原生的「聚焦元素自動捲入可視範圍」行為:

- 標題「抽獎系統」(`<h1 id="appTitle" tabindex="-1">`)與頁尾「作者: light0986」(`<footer id="authorFooter" tabindex="-1">`)都額外加了 `tabindex="-1"`,讓它們可以被 JavaScript 呼叫 `.focus()`,但不會出現在一般 Tab 鍵瀏覽順序裡(不影響鍵盤操作動線),CSS 也拿掉了這兩個元素被 focus 時預設的外框樣式,不影響視覺。
- 共用函式 `focusForScroll(el)`:包一層 `requestAnimationFrame`,確保在瀏覽器完成當下版面計算後才呼叫 `el.focus({ preventScroll: false })`,交由瀏覽器自動把該元素捲入可視範圍。
- 「開始抽獎」時呼叫 `focusForScroll(appTitleEl)` → 聚焦標題,等於捲到最上方。
- 得獎項目加入右側名單時呼叫 `focusForScroll(authorFooterEl)` → 聚焦頁尾作者署名,等於捲到最下方。
- 兩者都只在 `isStackedLayout()` 判斷為真(上下堆疊版面)時才觸發,寬螢幕左右並排時不會搶走使用者當下的捲動位置。

## 音效

音效控制列(寬螢幕左上角固定懸浮 / 窄螢幕上下堆疊時改為標題正下方,見上方響應式設計說明):

- **音量拉桿**:0 ~ 1,預設 0.5,即時調整所有音效的主音量。
- **開關 checkbox**:預設打勾,取消勾選則完全不發出任何音效。
- **測試按鈕**:點擊直接播放一次中獎音效,方便調整音量/音色時試聽,不影響抽獎流程。

所有音效皆用 **Web Audio API 即時合成**,不需要載入任何音檔:

| 音效 | 觸發時機 | 實作方式(對應函式) |
|---|---|---|
| 「嘟」聲 | 跑動特效每切換一個項目 | `playBeep()`:方波(square)短音,700Hz |
| 中獎喇叭聲 | 得獎項目實際加入右側名單的當下 | `playWinSound()` → `playHornNote()`:鋸齒波(sawtooth)+ 低通濾波器 + 起音滑音,模擬銅管喇叭音色,兩聲同音高(880Hz)分別 0.28 秒 / 0.5 秒 |

### 常用調整位置(於 `index.html` 的 `<script>` 區塊內)

- 音量預設值:`<input type="range" id="volumeSlider" ... value="0.5">`
- 中獎音效音高/節奏:`playWinSound()` 內的 `playHornNote(now, 880, 0.28)` 等呼叫,三個參數依序是「開始時間、音高(Hz)、持續秒數」。
- 中獎音色細節(波形、濾波器、起音滑音幅度):`playHornNote()` 函式內部。
- 跑動節奏(固定/漸緩秒數、每項間隔):`spinTo()` 內的 `fixedStepDelay` / `fixedStepCount` / `decelDuration` / `minLoops` 等常數。
- 清單最低高度:`.list-box` 的 `min-height: 500px`。
- 上下堆疊的斷點(目前 640px):`@media (max-width: 640px)`,以及 JS 裡對應判斷用的 `isStackedLayout()`(判斷式需跟 CSS 斷點保持一致)。
- 自動捲動的時機/目標元素:`drawWinner()` 裡的 `focusForScroll(appTitleEl)`(捲到最上)、`finishDraw()` 裡的 `focusForScroll(authorFooterEl)`(捲到最下),詳見上方「自動捲動實作方式」。

## 技術重點

- 純前端單一 HTML 檔,無任何外部相依套件、無需伺服器,雙擊即可在瀏覽器開啟使用。
- 兩個清單皆為自製的 `div` 清單(非原生 `<select>`),以取得完整的 CSS 控制能力(紅色外框跑馬燈效果、粗體抬頭、刪除按鈕展開動畫)。
- 抽獎結果為前端亂數(`Math.random()`),僅適合一般聯誼/尾牙/課堂等場合的公開抽獎展示用途,非密碼學等級亂數,不建議用於具高度公平性稽核需求的正式抽獎(如涉及金錢獎項的商業促銷活動)。

## 已知限制 / 待確認事項

- 抽獎按鈕預設「刪除中獎項目」勾選,如需改成預設不刪除(允許重複中獎),可直接把 HTML 裡 `soundEnabledCheckbox` 旁的 `removeOnWinCheckbox` 的 `checked` 屬性移除。
- 目前只支援單次抽一位得獎者,如需一次抽多位,需另外擴充。
